# 租金付款确认表自动生成（基站场地租赁报账）

> 基站租金报账时，付款确认表里的引用公式指着总表第几行，你敢手改吗？改错一行 = 错一笔钱。输入报账总表 + 合同台账，报一个合同编号，公式修正、字段补填、规范命名一步到位。

## 为什么需要它

用 GDZDY-011 模板做基站房屋/场地租赁付款确认表（会计事项 10040102 / 10040113）的人都知道这个坑：

目标表格的第 6 行是**跨工作簿外部链接公式**（引用报账总表 .xls 的具体行）。每个合同对应总表不同行，手工改公式时：

- 用 openpyxl 重新保存 → externalLinks 部件丢失 → 公式直接 `#REF!`
- 手工 COM 改错行号 → 引用到别的合同 → **金额对不上，审计时才发现**
- 银行账号、详细地点还要去台账里翻列补填，纯手工逐格拷贝

每月几十份确认表，每份都是这个流程。本工具把它变成一条命令。

## 功能亮点

| 能力 | 说明 |
|------|------|
| 自动定位 | 按合同编号在报账总表定位行号；同合同多期时自动取最新报账期间 |
| 公式修正 | Excel COM 会话内修正 A6/C6/D6/G6/H6/I6 外部链接公式行号，原生保存不丢 externalLinks |
| 字段补填 | 详细地点（B6）与银行帐号（F6）从合同台账自动带入；开户银行无来源时留空不臆造 |
| 规范命名 | 自动重命名为 `10040102房屋土地场地租赁<地点><金额>.xlsx` |
| 打开验证 | 写入后自动重新打开（UpdateLinks=3）验证公式生效值 |

## 快速开始

```bash
git clone https://github.com/cctvgh/rent-payment-confirm.git
cd rent-payment-confirm

# 报账文件夹内放好：报账总表(.xls) + 合同台账(.xlsx) + 目标确认表(.xlsx)
python scripts/build_rent_confirm.py --folder <报账文件夹> --contract <合同编号>
```

可选参数：`--period` 指定报账期间、`--file` 指定目标表、`--rename` 自定义命名。

完整工作流、单元格-列映射、常见陷阱（openpyxl 保存丢外部链接、外部链接按目标文件目录解析等）见 `references/workflow.md`。

- 财务共享中心处理批量租赁凭证的审核人员
- 任何需要批量修正 Excel 跨文件引用公式的办公场景
