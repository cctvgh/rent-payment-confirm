
# 租金付款确认表工作流参考（GDZDY-011 / 10040102）

## 1. 数据源文件与 sheet 布局

### 1.1 报账总表（`报账总表费用确认表YYYYMM.xls`）

关键 sheet：`202503报账总表XX市电信基站租金费用确认表`（表头在第 1 行）

| 列 | 表头 | 用途 |
|---|---|---|
| A | 序号 | — |
| B | 报账期间 | 如 202605；同一合同会有多个期间行 |
| C | 基站地址 | → A6 租赁点名称 |
| D | 合同编号 | → C6 |
| E | 合同名称 | — |
| F | 租赁期间起 | → G6 结算起始日 |
| G | 租赁期间止 | → H6 结算终止日 |
| H | 电信物理站址名称 | — |
| I | 业主名称 | → D6 收款方名称 |
| J | 付款金额（元） | → I6 结算租金金额 |

注意：总表里同一合同可能有多行（不同报账期间），取哪一行由报账期间决定；模板缓存值可能与当前总表不一致（如行号 2 是白石垌，但缓存是新屋仔），因此**必须以合同编号+期间重新定位行号并更新公式**。

### 1.2 合同台账（`合同台帐查询_YYYYMMDD.xlsx`）

sheet：`合同台帐查询`（自动匹配「合同」+「台账/台帐」）。列名映射：

| 台账列名 | 用途 |
|---|---|
| 合同编码 | 合同编号（D 列定位） |
| 房屋地址 | → B6 详细地点 |
| 开户账号 | → F6 银行帐号 |
| 开户名称 | 收款方（与总表 I 列一致） |
| 租赁面积 / 年租金 | 校验用 |

## 2. 核心脚本 `build_rent_confirm.py`

### 2.1 参数

```text
--folder   报账文件夹（必填）
--contract 合同编号（必填，如 GDZJG2600487AGN00）
--period   报账期间（可选；不填取最新一期）
--report   报账总表路径（可选；默认自动在 folder 查找）
--ledger   合同台账路径（可选；默认自动查找）
--file     目标 xlsx 路径（可选；默认 folder 内唯一 10040102*.xlsx）
--rename   保存后重命名的文件名（可选）
```

### 2.2 执行顺序

1. `locate_record_row`：pandas 读总表 sheet，按合同编号（D 列）筛选，期间匹配（默认取 B 列最大）；返回 Excel 行号 = pandas 索引 + 1。
2. `load_contract`：pandas 读台账，按合同编码返回房屋地址/开户账号/开户名称等。
3. `fix_formulas_and_fill`：COM 打开目标 xlsx（`UpdateLinks=0`），用正则 `!([A-Z]+)\d+$` 把 A6/C6/D6/G6/H6/I6 公式行号替换为目标行；写 B6/F6；`Save()`。
4. `verify_values`：重新打开（`UpdateLinks=3`）打印 A6..I6 的值。

### 2.3 重要

- 脚本依赖 `pandas` 与 `win32com`（pywin32）。
- 若台账 sheet 名或列名与默认不同，改 `load_contract` 中映射。
- 目标文件含外部链接时禁用 openpyxl 保存（会丢 externalLinks 部件）。

## 3. Excel COM 外部链接处理要点

- **写入公式**：在源文件打开状态下，Excel 实时解析 `[1]Sheet!B6` 并注册 externalLink 部件。脚本在 COM 会话里直接改 Formula 字符串即可，保存由 Excel 原生执行。
- **验证**：`Workbooks.Open(path, UpdateLinks=3)` 打开后读值；若值仍为旧缓存（刷新行为分场景），显式调用 `wb.UpdateLink(源, 1)` 逐源刷新后再读。
- **WPS 占用检测**：`wb.ReadOnly` 为 True 时说明 WPS/Excel 已打开，保存会静默失败（`DisplayAlerts=False` 吞掉提示），须提示用户先关闭。
- **公式计数对比**：`ws.Cells.SpecialCells(-4123, 23).Count`（xlCellTypeFormulas）前后应一致。

## 4. 常见坑与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 保存后 #REF! | 用 openpyxl 保存了含外部链接文件 | 改回 COM 会话原生保存 |
| ReadOnly=True 保存无效果 | WPS 打开中 | 请用户关闭 WPS 后重试 |
| 值显示白石行/其他合同 | 公式行号未更新或更新到旧行 | 用 --period 指定目标期间重新定位 |
| 台账 sheet 找不到 | sheet 名非「合同台帐查询」 | 脚本已自动匹配「合同」+「台账/台帐」 |
| 台账列映射错 | 列名变体（如"银行账号"） | 调整 load_contract 的列名集合 |
| 文件名不符 | 未重命名 | 按 `10040102房屋土地场地租赁<地点><金额>.xlsx` 规范 |

## 5. 命名规范

最终文件名：`10040102房屋土地场地租赁<地点><金额>.xlsx`
示例：`10040102房屋土地场地租赁XX区石城四清村18000.xlsx`、`10040102房屋土地场地租赁XX镇XX村19000.xlsx`。
地点取自总表「基站地址」或台账「房屋地址」的核心地点，金额取自该期付款金额。
